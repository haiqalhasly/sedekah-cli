# Sedekah CLI

This project is a to-do app with a twist. You can finish the tasks and gained coins. After that, you can give your coins to other as an act of kindness.

## Features:

- **Authentication**: Users can login with session-based approach. When you login, a session.json will be created and you will be authenticated using that.
- **Track your coin**: User can keep track of their coin
- **List Tasks**: Users can list all tasks or filter them by status. The statuses available for filtering are "all", "done", "todo", and "in-progress".
- **Sedekah**: Users can gives their coins to others as an act of kindness.
- **Mark Task as Done**: Tasks can be marked as "done" by specifying their ID.

## Command 

- login name password
- logout
- mark-done deed_id
- coin
- sedekah -to user_id

## How to use?:

- Just clone this repository
- Run in your IDE
- Go to your terminal add type python doit.py -h
- You will be given all the function or just refer to the video above
